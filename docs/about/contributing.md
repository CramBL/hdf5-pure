# Contributing

Contributions go through the [repository on GitHub](https://github.com/CramBL/hdf5-pure). Three documents apply to every contribution:

- [CONTRIBUTING.md](https://github.com/CramBL/hdf5-pure/blob/main/CONTRIBUTING.md): bug reports, feature requests, pull requests, commits and tests.
- [AI_POLICY.md](https://github.com/CramBL/hdf5-pure/blob/main/AI_POLICY.md): the use of AI in contributions.
- [CODE_STYLE.md](https://github.com/CramBL/hdf5-pure/blob/main/CODE_STYLE.md): the code style.
